# STOU Fast-Track Learning System (ตัวช่วยเรียน มสธ. x สจล.) 🚀

ระบบเว็บแอปพลิเคชันช่วยเรียนและเตรียมสอบมหาวิทยาลัยสุโขทัยธรรมาธิราช (มสธ.) สำหรับนักศึกษาโครงการสัมฤทธิบัตร และผู้ที่กำลังเรียนควบปริญญาตรี (สจล. x มสธ.)

## 🎯 ไฮไลต์ฟีเจอร์หลัก

1. **80/20 High-Yield Summary (คัดกรองจากตำรา 1,000 หน้า)**
   - สรุปย่อเน้นเฉพาะ **วัตถุประสงค์เชิงพฤติกรรม** และ **สาระสังเขป** ที่ออกสอบจริง
   - มีชุดวิชาเริ่มต้น:
     - **10141**: วิทยาศาสตร์ เทคโนโลยีและสิ่งแวดล้อมเพื่อชีวิต (ครบ 15 หน่วย)
     - **10151**: ไทยศึกษา (ครบ 15 หน่วย)
2. **Active Recall & Exam Simulator**
   - คลังข้อสอบตามแนวแบบประเมินตนเองก่อน-หลังเรียนของ มสธ.
   - แสดงเฉลยและเหตุผลเชิงลึกทันทีที่เลือกตอบ พร้อมวิเคราะห์สถิติจุดอ่อน
3. **KMITL-Shield Time Optimizer (ระบบป้องกันเวลาเรียน สจล.)**
   - คำนวณตารางเรียนแบบ **Micro-Learning 15 นาที** โดยใช้เฉพาะเศษเวลาเดินทาง (Airport Rail Link / รถไฟลาดกระบัง)
   - มี **โหมดสัปดาห์สอบ สจล.** เพื่อพักภาระ มสธ. 100% รักษาเกรดภาษาจีนอันดับ 1
4. **STOU Official Media Direct Links**
   - รวมลิงก์คลิปเสียงและวิดีโอบรรยายทางการของ มสธ. Channel บน YouTube แยกรายหน่วย
5. **Commercial Blueprint (พิมพ์เขียวการทำขาย)**
   - โมเดลราคา (Freemium, ฿199/วิชา, ฿499 Bundle)
   - กลยุทธ์การตลาดผ่านกลุ่มนักศึกษา มสธ. และ TikTok

## 💻 วิธีการเปิดใช้งาน (Run Locally)

เปิด Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
# 1. ติดตั้ง Dependencies (ทำครั้งแรก)
npm install

# 2. เริ่มต้นรันเซิร์ฟเวอร์
npm run dev
```

เปิด Browser ไปที่: `http://localhost:3000`

### 📱 วิธีเปิดใช้บนโทรศัพท์มือถือ (ช่วงนั่งรถไฟ/แอร์พอร์ตลิงก์)
- ให้อุปกรณ์และคอมพิวเตอร์ต่อ Wi-Fi วงเดียวกัน
- ดู IP Address ของเครื่องคอมพิวเตอร์ เช่น `http://192.168.1.XX:3000` แล้วเปิดใน Safari หรือ Chrome บนมือถือได้เลย!

## 🌐 การนำไป Deploy ขึ้นออนไลน์ (เพื่อใช้งานจริงและเริ่มทำขาย)

โปรเจกต์นี้เขียนด้วย **Vite + React** สามารถนำไป Deploy ได้ฟรี 100% ภายใน 2 นาที:
- **Vercel**: อัปโหลดขึ้น GitHub แล้วเชื่อมต่อกับ Vercel กด Deploy ได้ทันที
- **Netlify**: ลากโฟลเดอร์ `dist` (หลังรัน `npm run build`) วางบนหน้าแดชบอร์ดของ Netlify ได้เลย
